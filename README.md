# 发泄山谷（Venting Valley）

一个**纯单机**的情绪发泄小应用：把烦心事写下来或说出来，丢进山谷，风会带走它。

- 文字 / 语音倾诉，消息卡片样式
- 定时自动焚烧：说过的话到点就烧掉，不留痕迹
- 焚烧动画、心情询问、日夜主题
- 无账号、无上报、无后台请求

## 隐私承诺

- **不上传**：文字和录音只存在这台手机上，不收集任何隐私
- **平时不联网**：没有任何后台请求、自动更新或数据上报
- **唯一联网**：你主动点「检查更新」时，才临时访问本仓库的版本信息
- **焚烧即彻底删除**，卸载 App 时数据一并清除
